# Stage U: Clean User Interface Redesign & Accessibility Verification

_Date: 2026-11-08 | Branch: `v0.4.0a` | Zero 3rd-Party Dependencies | Cap: $0_

---

## 1. UI Problems Identified Before Redesign

Prior to Stage U, the Lantern Vault web studio (`examples/lantern-vault/web/`) was evaluated across desktop and mobile viewports. The following defects and accessibility problems were identified:

1. **No Dedicated Inventory Bag**:
   - *Problem*: Player inventory was invisible as a dedicated bag; items were only discoverable when embedded inside action dropdown buttons (e.g. `Inspect salve`).
   - *Fix*: Created a dedicated `Shared Purse & Expedition Gear` panel with `#inventory-items`, displaying carried items, category tags (`healing`, `supply`, `token`), and interactive `Inspect` buttons.

2. **No Dedicated Characters Present Section**:
   - *Problem*: Characters in the chamber were only indicated by a small `<select id="npc">` dropdown and a text badge (`#presence`), leaving players uncertain who was nearby (merchant, keeper, or animal companion).
   - *Fix*: Added `#characters-present-card` with `#characters-list`, explicitly listing present figures (Ilen the Merchant, Keeper of the Seals, or the Cave Hound companion) with quick `Speak` shortcuts.

3. **Missing Timeline Chronicle & Lore Journal**:
   - *Problem*: Rich timeline lore and milestone events generated by the world model (ancient history, cistern breakdown, player achievements) were entirely unrendered in the UI.
   - *Fix*: Added `#journal-card` and `#journal-entries` powered by new `/api/journal` and `/api/timeline` endpoints, displaying chronological entries with era tags (`history`, `epoch`, `milestone`, `local`), titles, and summaries.

4. **Rigid, Clunky Layout on Mobile & Desktop**:
   - *Problem*: The layout used a rigid 3-column CSS grid that broke on medium screens and stacked clumsily on mobile devices (< 768px).
   - *Fix*: Implemented a modern CSS grid layout (`.play-layout`) with responsive breakpoints:
     - **Desktop (> 1200px)**: 3-column layout (Scene & Characters | Dialogue & Speech | Actions Hub & Journal).
     - **Tablet (768px–1200px)**: 2-column layout with actions and journal spanning the bottom.
     - **Phone (< 768px)**: Single column with natural reading order (Dialogue -> Scene & Characters -> Actions Hub -> Inventory -> Journal).

5. **No Light Theme & Low Contrast Ratios**:
   - *Problem*: Only hardcoded dark mode existed; several muted text colors (`#9eafb3` on `#101a20`) had borderline contrast on small viewports.
   - *Fix*: Built complete CSS custom property themes for `[data-theme="dark"]` and `[data-theme="light"]` with high-contrast text (`#f0ede6` on `#0c1418` dark; `#16242c` on `#f4f6f8` light) and an interactive `#theme-toggle` button with `localStorage` persistence.

6. **Inconsistent Keyboard Navigation & Focus Rings**:
   - *Problem*: Several buttons and form inputs lacked visible focus rings, failing WCAG 2.1 AA focus visible criteria.
   - *Fix*: Added universal visible focus styling: `*:focus-visible { outline: 2px solid var(--accent) !important; outline-offset: 2px !important; }`.

7. **Disorganized World Actions**:
   - *Problem*: World actions (movement, trade, crafting, animal interaction, pump repair) were lumped together in an unorganized list.
   - *Fix*: Restructured into clear visual action sections: quick navigation (`#quick-actions`), trade shortcuts (`#stock`, `#promise`), and complete collapsible world actions (`#actions`).

8. **Unclear Loading & Thinking States**:
   - *Problem*: When a model was thinking or slow, user feedback was ambiguous.
   - *Fix*: Added an animated CSS spinner and status message (`.thinking-state`) with an instant fallback button (`#use-instant-reply`).
